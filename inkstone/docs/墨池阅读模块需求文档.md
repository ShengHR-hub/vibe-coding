# 墨池 Inkstone · 阅读模块需求文档

> 版本：v1.0  日期：2026-06-14  状态：需求确认

---

## 一、项目背景

墨池（Inkstone）是一个 AI 驱动的全品类写作社交平台，已完成 17 个写作模块、103 个 API 端点、20 个前端页面。现计划新增**阅读模块**，使墨池成为"读写一体"的完整创作生态。

**核心理念**：写作时通过阅读积累经验和灵感，阅读时通过写作功能缓解疲劳和激发创作。读与写相互滋养、深度融合。

---

## 二、模块总览

| 维度 | 目标 |
|------|------|
| 定位 | 完整阅读平台 = 沉浸式阅读器 + 数字书库 + 阅读社交 |
| 内容来源 | 平台内用户创作作品 + 外部导入书籍（TXT） |
| 内容类型 | 小说、散文、诗歌、网文 |
| 视觉风格 | 统一墨池风格（毛玻璃 + 金色点缀） |
| 规模 | 与写作模块对等，预计 10-14 个子模块、80-100 个端点 |
| 实施策略 | 按功能链条推进：导入 → 书库 → 书架 → 阅读器 → 批注 → 打卡 → 报告 |

## 三、功能模块详细设计

### 模块 1：书库系统

统一管理平台内作品和外部导入书籍，提供分类、搜索、排行榜。

#### 1.1 书库首页

| 功能 | 说明 |
|------|------|
| 精选推荐 | 编辑精选 / AI 推荐 / 热门榜 / 新书榜 |
| 分类浏览 | 按类型（小说/散文/诗歌/网文）、按标签、按字数范围 |
| 全文搜索 | 书名、作者、内容全文检索 |
| 排行榜 | 热度榜、收藏榜、评分榜、完本榜、连载榜 |

#### 1.2 书籍详情页

| 功能 | 说明 |
|------|------|
| 基本信息 | 书名、作者、简介、标签、字数、章节数、连载状态 |
| 数据展示 | 阅读量、收藏数、评分、评论数 |
| 目录 | 按卷/章展示，标注已读进度 |
| 操作入口 | 开始阅读、加入书架、分享、举报 |
| 书评区 | 长评 + 短评，支持点赞和回复 |
| 相似推荐 | AI 推荐同类型作品 |

#### 1.3 书籍导入

| 功能 | 说明 |
|------|------|
| 后台批量导入 | 管理员通过脚本批量导入 TXT 文件（复用/增强 import_novel.py） |
| 前端用户上传 | 登录用户可上传个人 TXT 文件，自动解析章节、提取元信息 |
| 格式支持 | TXT（UTF-8/GBK/GB18030 自动检测编码） |
| 解析规则 | 自动识别书名、作者、章节标题，支持自定义章节正则 |
| 去重检测 | 同名同作者的书籍提示已存在 |

**新增数据库表**：

```sql
-- 外部导入书籍表（区别于用户创作的 works 表）
CREATE TABLE library_books (
    book_id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    author VARCHAR(100) NOT NULL,
    summary TEXT,
    cover_image VARCHAR(500) DEFAULT '',
    type ENUM('novel', 'essay', 'poetry', 'webfiction') DEFAULT 'novel',
    tags VARCHAR(500) DEFAULT '',
    word_count INT DEFAULT 0,
    chapter_count INT DEFAULT 0,
    serialization_status ENUM('serializing', 'completed', 'paused') DEFAULT 'completed',
    source VARCHAR(100) DEFAULT '',  -- 来源标记
    uploader_id INT DEFAULT NULL,   -- 上传者
    views INT DEFAULT 0,
    favorites_count INT DEFAULT 0,
    rating_avg DECIMAL(3,2) DEFAULT 0,
    rating_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (uploader_id) REFERENCES users(user_id) ON DELETE SET NULL,
    INDEX idx_book_type (type),
    INDEX idx_book_created (created_at)
);

CREATE TABLE library_chapters (
    chapter_id INT AUTO_INCREMENT PRIMARY KEY,
    book_id INT NOT NULL,
    volume_id INT DEFAULT NULL,
    chapter_no INT NOT NULL,
    title VARCHAR(200) DEFAULT '',
    content LONGTEXT,
    word_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (book_id) REFERENCES library_books(book_id) ON DELETE CASCADE,
    INDEX idx_lch_book (book_id)
);

CREATE TABLE library_volumes (
    volume_id INT AUTO_INCREMENT PRIMARY KEY,
    book_id INT NOT NULL,
    volume_no INT NOT NULL,
    title VARCHAR(200) DEFAULT '',
    summary TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (book_id) REFERENCES library_books(book_id) ON DELETE CASCADE
);
```

> 说明：library_books 与 works 分开存储，因为来源和管理方式不同。平台内作品通过 works 表的 status=published 在书库中展示，外部导入书籍存入 library_books。

### 模块 2：个人书架

用户管理自己的阅读记录和书籍收藏。

| 功能 | 说明 |
|------|------|
| 在读 | 有阅读进度但未读完的书籍，显示进度百分比 |
| 已读 | 用户标记为"已读完"的书籍 |
| 想读 | 收藏但尚未开始阅读的书籍 |
| 自定义书单 | 用户创建自定义分类（如"仙侠必读"、"写作参考"） |
| 排序筛选 | 按最近阅读、加入时间、评分、字数排序 |
| 批量管理 | 批量移动分组、批量删除 |

**新增数据库表**：

```sql
CREATE TABLE reading_bookshelf (
    shelf_id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    book_type ENUM('work', 'library') NOT NULL,  -- 来源：平台作品 or 导入书籍
    book_id INT NOT NULL,                          -- 对应 works.work_id 或 library_books.book_id
    shelf_group ENUM('reading', 'finished', 'want_read') DEFAULT 'want_read',
    custom_folder VARCHAR(100) DEFAULT '',
    rating TINYINT DEFAULT 0,                      -- 用户评分 1-5
    added_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE,
    UNIQUE KEY uk_bookshelf (user_id, book_type, book_id),
    INDEX idx_shelf_user (user_id, shelf_group)
);
```

### 模块 3：沉浸式阅读器

专注于极致的阅读体验。

#### 3.1 阅读界面

| 功能 | 说明 |
|------|------|
| 滚动阅读 | 上下连续滚动，类似微信读书默认模式 |
| 顶部工具栏 | 返回、目录、设置、批注、分享 |
| 底部信息栏 | 当前章节、阅读进度百分比 |
| 章节切换 | 顶部下拉章节列表（复用 Reader.vue 的毛玻璃下拉样式） |
| 自动隐藏 | 阅读时工具栏自动隐藏，点击屏幕中央唤出 |

#### 3.2 阅读设置

| 功能 | 说明 |
|------|------|
| 字体大小 | 12px ~ 28px 滑块调节 |
| 行间距 | 1.5 / 1.8 / 2.0 / 2.5 四档 |
| 字体选择 | 系统默认 / 宋体 / 楷体 / 黑体 |
| 背景主题 | 默认暗色 / 护眼绿 / 羊皮纸 / 纯白 / 纯黑 |
| 亮度调节 | 软件级亮度调节（CSS filter） |
| 翻页方式 | 滚动（默认） |
| 设置持久化 | 所有设置存入 localStorage，全局生效 |

#### 3.3 阅读进度

| 功能 | 说明 |
|------|------|
| 自动记录 | 每 10 秒自动保存当前阅读位置（章节 + 段落偏移） |
| 跨设备同步 | 登录状态下进度存服务端，换设备可恢复 |
| 进度展示 | 书架显示每本书的阅读百分比 |
| 续读提示 | 打开已读过的书，提示"上次读到第X章，是否继续" |

**新增数据库表**：

```sql
CREATE TABLE reading_progress (
    progress_id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    book_type ENUM('work', 'library') NOT NULL,
    book_id INT NOT NULL,
    chapter_id INT NOT NULL,
    scroll_percent DECIMAL(5,2) DEFAULT 0,  -- 滚动位置百分比
    total_percent DECIMAL(5,2) DEFAULT 0,   -- 全书阅读进度百分比
    last_read_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE,
    UNIQUE KEY uk_progress (user_id, book_type, book_id)
);
```

```sql
CREATE TABLE reading_annotations (
    annotation_id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    book_type ENUM('work', 'library') NOT NULL,
    book_id INT NOT NULL,
    chapter_id INT NOT NULL,
    paragraph_idx INT DEFAULT 0,

    content TEXT NOT NULL,
```

### 模块 6：书评与评分

对读完的书进行评价。

| 功能 | 说明 |
|------|------|
| 短评 | 一句话评价 + 1-5 星评分 |
| 长评 | 结构化书评（类似 AI 书评的四段式） |

| 书评排序 | 最新、最热、最高分、最低分 |
| AI 辅助写书评 | 一键生成 AI 书评草稿，用户修改后发布 |

**新增数据库表**：

```sql
CREATE TABLE reading_reviews (
    review_id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    book_type ENUM('work', 'library') NOT NULL,
    book_id INT NOT NULL,
    rating TINYINT NOT NULL,        -- 1-5 星
    title VARCHAR(200) DEFAULT '',
    content TEXT,
    is_long_review BOOLEAN DEFAULT FALSE,
    likes_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE,
    UNIQUE KEY uk_review (user_id, book_type, book_id),
    INDEX idx_review_book (book_type, book_id)
```

## 四、读写联动设计

### 4.1 学习型联动

| 触发点 | 联动方式 |
|------|------|
| 阅读时做批注 | 批注内容可一键发送到写作素材库 |
| 阅读时标记好句 | 好句自动归入"灵感素材"分类 |
| 阅读书评 | AI 书评的"风格分析"可作为写作参考 |

### 4.2 灵感型联动

| 触发点 | 联动方式 |
|------|------|
| 阅读中突发灵感 | 底部"记灵感"按钮，快速记录不离开阅读 |
| 读到精彩情节 | "仿写"按钮，以当前段落为上文调用 AI 续写 |
| 角色对话有趣 | "角色扮演"按钮，跳转到 RP 模块以该角色对话 |

### 4.3 数据型联动

| 触发点 | 联动方式 |
|------|------|
| 阅读时长 | 阅读时长转化为经验值（每 10 分钟 = 1 经验） |
| 阅读打卡 | 连续打卡解锁成就（"书虫"系列成就） |
| 个人中心 | 统一展示写作数据 + 阅读数据的综合面板 |
| 排行榜 | 新增"阅读达人榜"（阅读时长/书籍数） |

### 4.4 素材联动

| 功能 | 说明 |
|------|------|
| 阅读笔记 → 素材库 | 批注和标记的好句自动同步到写作素材库 |
| 素材库来源标记 | 标记素材来自哪本书的哪个段落 |
| 灵感面板集成 | 写作工作室的灵感面板可引用阅读笔记 |

**新增数据库表**（联动）：

```sql
CREATE TABLE reading_highlights (
    highlight_id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    book_type ENUM('work', 'library') NOT NULL,
    book_id INT NOT NULL,
    chapter_id INT NOT NULL,
    paragraph_idx INT DEFAULT 0,
    selected_text TEXT NOT NULL,
    note VARCHAR(500) DEFAULT '',
    synced_to_material BOOLEAN DEFAULT FALSE,  -- 是否已同步到素材库
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE,
    INDEX idx_hl_user (user_id)
);
```

## 九、实施计划

按功能链条推进，每条链走通再开始下一条：

### 链条 1：导入 → 书库（3-4 天）

```
TXT 文件 → 解析入库(library_books + library_chapters)
→ 书库首页(列表/搜索/分类/排行)
→ 书籍详情页(信息/目录/操作)
→ 用户上传功能
```

### 链条 2：书架 → 阅读器（3-4 天）

```
加入书架 → 书架页面(在读/已读/想读/书单)
→ 沉浸式阅读器(滚动/工具栏/章节切换)
→ 阅读设置(字体/行距/主题)
→ 阅读进度(自动保存/跨设备同步/续读提示)
```

### 链条 3：书签 → 批注（2-3 天）

```
添加书签 → 书签列表/跳转
→ 段落批注(创建/编辑/公开性切换)
→ 公开批注展示/回复
→ 我的批注列表
```

### 链条 4：打卡 → 报告（2-3 天）

```
自动打卡 → 打卡日历/连续天数
→ 阅读时长记录
→ 个人中心阅读数据(周/月/趋势)
→ 年度阅读报告(沉浸式/分享卡片)
```

### 链条 5：读写联动（1-2 天）

```
好句标记 → 同步到素材库
→ 阅读灵感快速记录
→ 经验值/成就联动
→ 导航栏统一入口(首页改版)
```

**总计预计：11-16 天**
