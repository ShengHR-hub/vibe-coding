### 步骤 1.2：增强 import_novel.py

**文件**：`server/database/import_novel.py`

改造 `import_to_db()` 函数，新增 `--target` 参数：
- `--target works`（默认，导入到 works + chapters，现有行为）
- `--target library`（导入到 library_books + library_chapters）

新增函数 `import_to_library(novel, user_id)`：
- 计算总字数
- 插入 library_books 表
- 逐章插入 library_chapters 表
- 返回 book_id

测试：用现有 TXT 文件导入到 library_books，确认数据正确。

### 步骤 1.3：新建 library.py 蓝图 — 基础端点

**文件**：`server/routes/library.py`

创建蓝图 `library_bp`，先实现 3 个基础端点：

```
GET /api/library          — 书库列表（分页 + 筛选 + 排序）
GET /api/library/:id      — 书籍详情
GET /api/library/:id/chapters — 章节列表
```

**GET /api/library 逻辑**：
- 合并查询 `works`（status='published'）和 `library_books`
- 支持参数：`page`, `page_size`, `type`, `sort`（hot/new/rating）
- 返回统一格式：`{ book_id, title, author, type, word_count, chapter_count, rating_avg, views, cover_image, source: 'work'|'library' }`

**GET /api/library/:id 逻辑**：
- 根据 `source` 参数区分查 works 还是 library_books
- 返回书籍信息 + 章节目录 + 是否在书架 + 用户评分

**GET /api/library/:id/chapters 逻辑**：
- 根据 source 查 chapters 或 library_chapters
- 支持按 volume_id 分组

### 步骤 1.9：新增 /api/library/upload 端点

**文件**：`server/routes/library.py`

```

```

接收 multipart/form-data：

- `title`（可选）：书名，不传则自动解析

3. 去重检查（同名同作者）

5. 返回 book_id

### 步骤 2.2：新建 bookshelf.py 蓝图

**文件**：`server/routes/bookshelf.py`

创建蓝图 `bookshelf_bp`，实现 6 个端点：

```
GET  /api/bookshelf             — 书架列表（按 group 筛选）
POST /api/bookshelf             — 加入书架
PUT  /api/bookshelf/:id         — 更新分组/评分/书单
DELETE /api/bookshelf/:id       — 从书架移除
GET  /api/bookshelf/folders     — 自定义书单列表
POST /api/bookshelf/folders     — 创建书单
```

**POST /api/bookshelf 逻辑**：
- 接收 `{ book_type, book_id, shelf_group }`
- 检查是否已在书架（UNIQUE 约束）
- 插入 reading_bookshelf

**GET /api/bookshelf 逻辑**：
- 查询当前用户的书架
- 关联查 books/chapters 获取最新阅读进度
- 支持 `group` 参数筛选

### 步骤 2.3：新建 reading.py 蓝图

**文件**：`server/routes/reading.py`

创建蓝图 `reading_bp`，实现 3 个端点：

```
GET /api/reading/progress/:type/:id  — 获取阅读进度
PUT /api/reading/progress/:type/:id  — 更新阅读进度
GET /api/reading/history             — 阅读历史
```

**PUT 进度逻辑**：
- UPSERT：存在则更新，不存在则插入
- 同时更新 `reading_bookshelf` 中的 `shelf_group` 为 `reading`（如果还是 `want_read`）
- 计算 `total_percent`（当前章节偏移 / 总章节数）

### 步骤 4.2：新建 checkin.py 蓝图

**文件**：`server/routes/checkin.py`

```
POST /api/reading/checkin            — 记录阅读（自动打卡）
GET  /api/reading/checkin/calendar?month= — 打卡日历
GET  /api/reading/checkin/streak     — 连续打卡天数
```

**POST 逻辑**：
- 接收 `{ read_minutes, pages_read, books_read }`
- UPSERT 到 reading_checkins（user_id + checkin_date 唯一）
- 如果今天已有记录，累加 read_minutes

---

### 步骤 4.3：新建 report.py 蓝图

**文件**：`server/routes/report.py`

```
GET /api/reading/report/weekly   — 本周数据
GET /api/reading/report/monthly  — 本月数据
GET /api/reading/report/annual   — 年度报告
GET /api/reading/report/trend?days=30 — 阅读趋势
```

**weekly 逻辑**：
- 查 reading_checkins 本周数据
- 聚合：总时长、读了几本、多少章
- 返回格式：`{ total_minutes, books_count, chapters_count, daily_breakdown: [...] }`

**annual 逻辑**：
- 查 reading_checkins 全年数据
- 聚合：总字数、书籍数、阅读时长、最晚阅读时间
- 查 reading_bookshelf 找"读过最长的书"、"读得最快的书"
- 返回格式：`{ total_words, books_count, total_minutes, latest_read_time, longest_book, fastest_book, monthly_data: [...], type_distribution: [...] }`
