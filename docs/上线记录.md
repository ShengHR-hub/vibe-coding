## 版本更新步骤
1. 本地打包：在仓库根打包（排除 .git/node_modules/results/env/logs）得到 tgz；
2. `scp` 上传到服务器 /tmp；
3. `sudo tar -xzf /tmp/inkstone.tgz -C /srv/inkstone`（覆盖代码与前端 dist）；
4. `sudo systemctl restart inkstone`；
5. 涉及数据库结构变化时，先按变更执行幂等 SQL（schema.sql 变更需人工在库执行，勿整体重灌，避免清空生产数据）。
