## 我方部署结构
| 组件 | 位置 |
|---|---|
| 代码与前端 dist | `/srv/inkstone`（上传自本仓库打包 tgz） |
| Python 环境 | `/srv/inkstone/server/.venv` |
| 生产配置 | `/srv/inkstone/server/.env`（SECRET_KEY/MySQL/MiMo，chmod 600） |
| 后端服务 | systemd `inkstone.service`（gunicorn 2 worker → 127.0.0.1:8000，开机自启） |
| Nginx | `/etc/nginx/conf.d/ink-inkstone.conf`（`server_name ink.shenghui2026.top`，SSE 关缓冲） |
| HTTPS | Let's Encrypt 证书（/opt/certbot 独立 venv 签发，自动续期由 systemd timer 接管） |
| 数据库 | MySQL 8 本地库 `inkstone`，应用账号 `inkstone`@localhost（密码存于 server/.env） |

```bash

sudo /opt/certbot/bin/certbot renew --dry-run   # 证书续期检查
sudo mysql --defaults-file=/etc/mysql/debian.cnf -e "SHOW DATABASES;"
```

## 版本更新步骤
1. 本地打包：在仓库根打包（排除 .git/node_modules/results/env/logs）得到 tgz；
2. `scp` 上传到服务器 /tmp；
3. `sudo tar -xzf /tmp/inkstone.tgz -C /srv/inkstone`（覆盖代码与前端 dist）；
4. `sudo systemctl restart inkstone`；
5. 涉及数据库结构变化时，先按变更执行幂等 SQL（schema.sql 变更需人工在库执行，勿整体重灌，避免清空生产数据）。
