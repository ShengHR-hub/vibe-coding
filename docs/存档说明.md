# 墨池 Inkstone · 存档说明（v2026.09.04 · 成书工作流版）

> 本存档对应 Git HEAD `35cc6cd`（2026-09-04，累计 58 个 commit）。用途：作为「AI 辅助成书」当前完成版的 GitHub 存档快照，可随时整体拉取、构建与回滚。

## 1. 版本定位一句话

墨池 = AI 写作灵感生态 + **成书工作流**：把"写一本书"当作工程项目，右侧写作台按
**起：定目标 → 承：稳推进 → 合：精收尾** 三阶段引导用户完成从立项蓝图到大纲、逐章写作、审校、到整书交付的闭环。

## 2. 本版包含（P1–P4）

| 阶段 | 内容 |
|---|---|
| **P1 写作主线强化** | AI 端点限流/每日配额(429)、输入上限、prompt 防注入、面板统一安全渲染、work_lore 设定记忆、续写携带作品上下文(简介/章节/角色/设定)、AI 会话历史与剪枝、结果落位 cursor/append/replace、素材 references 注入(续写/润色/对话) |
| **P2 书籍模块下线** | 移除书库/外部阅读(蓝图/表/页面/组件/文档)，保留原创作品管理 |
| **P3 灵感馆** | /inspire 统一翻阅(今日灵感+诗词/句子素材)、收藏个人池、手动收录句子、引用到创作 |
| **P4 成书工作流** | 三阶段右侧工作流 UI；立项蓝图(book_plans)、大纲规划器(卷/章+beats/钩子写回)、本章任务卡、按蓝图续写(注入下章计划)、结构审校(AI 报告)、[TODO]清单、整书交付(导出)；/write?work=ID 打开已有作品 |

配套：公开作品详情页（阅读器下线后，广场/排行等进入详情：简介+目录+点赞/收藏/评论，正文不公开）。

## 4. 快速启动（开发）

```bash
# 数据库（开发库）
mysql -u root -p < server/database/schema.sql
cd server && python -m database.seed

# 后端 5000
cd server && python app.py
# 前端 5173（/api 代理到 5000）
cd client && npm install && npm run dev
```

生产部署见 `docs/DEPLOY.md`；方向与进度文档见 `docs/`（灵感馆方向/写作强化计划/成书工作流方案/改造守则/改造进度）。
