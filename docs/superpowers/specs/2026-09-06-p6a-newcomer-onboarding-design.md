## 1. 背景与目标

用户反馈（2026-09-05 起多轮）：写书第一步没人告诉他该干什么；面板太多不知道点哪个；新手进来面对写作台手足无措。经头脑风暴收敛出的总方向（P6）：

- **新手向「创作工坊」**（独立 UI，向导式 0 灵感→1 主线→2 大纲→3 角色→4 动笔→5 反馈→6 交付）——二期
- **纯净写作页**（只有编辑区+保存+导出）——本期
- **闪念便签**（写作中随时记点子，怕忘）——本期
- **入口分流**：新手/老手/纯净三种模式，放使用说明弹窗内由用户自选，不强制——本期
- 广场/挑战/排行/练习/主页下部优化 → Backlog（锦上添花轮）

**一期范围（本文档）**：使用说明弹窗（含三种模式选择）、`/write/plain` 纯净写作页、主页「纯净写作」入口、写作台闪念便签（含数据层）。

## 2. 架构决策（用户两问的答案，固化下来）

### 2.1 数据共用三边界（"共用会不会乱"）
1. **库唯一、API 为界**：不新建「业务表」（作品/章节/大纲/设定等现有域一律复用）；前端一律走 API，不直连表。仅当出现**现有表装不下的新产品能力**（如便签）才开独立新表 + 新 API。
2. **权限固有隔离**：业务表均带 user_id/work_id，接口只返回本人数据；两套 UI 数据天然分区，不互相污染。
3. **字段语义不漂移**：工坊只读写现有字段，不往旧字段塞新含义；新数据（便签）开新表 user_notes + 新 API。

### 2.2 跨页上下文（"路由跳转会难受"）
- 复用现有轨道：`writingStore`（Pinia 全局，记住当前作品/章节/引用队列）、`inkstone:goto-tool` 自定义事件。不发明第三套。
- 跳出去再回来：状态在 store 里，落点不丢。
- 改相关路由/组件前，先画清关联（谁持有 work_id、谁写 pickedRefs）再动手。

## 3. 一期交付物

### A. 使用说明弹窗（首次进写作台 / 可再次打开）
- **触发**：首次进入 `/write`（本地标记未置位）时弹出；右上角/说明入口可再次打开；不强制、可关闭且不再打扰（可手动重开）。
- **内容**（正文占位，后续完善）：
  - 标题「从哪开始？」+ 三段简短说明文字（占位，锚点跳转到说明详文占位页）
  - 三张选择卡：**跟随引导（新手）** → 跳转创作工坊（二期占位：显示"建设中"，一期暂落现有写作台并提示）；**直接开始（老手）** → 关闭进现有写作台；**只想安静写** → 跳转 `/write/plain`
  - 选择结果存本地（localStorage `inkstone_mode`），再次进入不再弹；可手动改。
- **组件**：`client/src/components/OnboardingModal.vue`，挂载于 WriteStudio。

### B. 纯净写作页 `/write/plain`
- **路由**：`client/src/router/index.js` 新增 `{ path: '/write/plain', meta: { auth: true }, component: PlainWrite.vue }`
- **UI**：只有 作品标题 + 章节列表（极简）+ 编辑区 + 「保存」「导出」两个按钮；无右侧面板、无 AI 按钮、无浮动按钮。
- **数据**：复用现有 works/chapters API（读写同一批作品，与写作台互通——同一本书两边都能打开）。
- **组件**：`client/src/views/write/PlainWrite.vue`（新建）。

### C. 主页「纯净写作」入口
- Home Hero 区第三个 portal（社区广场旁）新增「纯净写作」卡片（`/write/plain`），或独立入口位——实现时以视觉协调为准，文案「纯净写作 · 无干扰 · 写完就走」。

### D. 闪念便签（数据层 + UI）
- **数据**：新表 `user_notes`（note_id PK、user_id、content TEXT、created_at/updated_at）；新蓝图 `routes/notes.py` 4 端点：
  - `GET /api/notes`（本人列表，倒序）
  - `POST /api/notes`（content 1-2000 字）
  - `PUT /api/notes/<id>`（仅本人，改内容）
  - `DELETE /api/notes/<id>`（仅本人）
- **UI**：写作台右下角悬浮「便签」按钮 → 弹出小面板（新增/列表/删除，最简可用）；快捷键（如 Ctrl+Shift+N）唤起；面板收起不丢失。
- **二期衔接**：`user_notes` 即「我的灵感」数据源之一，二期灵感馆新页签直接复用。

## 4. 测试与验收

- 后端：`server/tests/test_notes.py`（CRUD/越权/长度/登录 401，走 inkstone_test，AI 无关零 token）；pytest 全绿。
- 前端：`npm run build` 绿；手工冒烟路径：
