# 墨池 — AI智能创作与写作社交平台 · 需求文档

> 计算机科学与技术 · 本科毕业设计

---

## 一、项目概述

### 1.1 项目名称

墨池（Inkstone）— AI智能创作与写作社交平台

### 1.2 一句话定位

面向写作爱好者的全品类创作平台，融合 **AI写作助手**、**社区社交互动**、**数据洞察成长** 三大核心能力。

### 1.3 目标用户

网文作者、诗歌散文爱好者、剧本创作者、写作初学者等有创作意愿的人群。

### 1.4 核心价值

| 维度 | 用户痛点 | 解决方案 |
|------|----------|----------|
| AI辅助 | 卡文、缺乏灵感、文笔不佳 | AI续写/灵感/大纲/润色/角色生成 |
| 社交 | 写作孤独、缺少读者反馈 | 社区分享/评论互动/创作挑战/共创接龙 |
| 数据 | 不清楚自己的写作习惯和进步 | 字数统计/热力图/风格分析/月度报告 |

### 1.5 技术方案

| 层级 | 选型 |
|------|------|
| 前端 | Vue3 + Vite + Vue Router + Pinia |
| UI 风格 | 自定义 CSS（毛玻璃玻璃态/渐变/动效），深色+暖色主题 |
| 后端 | Python Flask 3.x + 蓝图模式 |
| 数据库 | MySQL 8.0 + PyMySQL（原生 SQL） |
| AI 大模型 | 小米 MiMo API（OpenAI 兼容格式，可切换） |
| 可视化 | ECharts 5.x CDN |
| 认证 | Session-based（Flask session） |
| 部署 | 零构建工具依赖，pip install 即启动 |

### 1.6 系统规模

- **10 大模块**
- **46 项子功能**
- **8+ 数据库表**
- **35+ API 端点**

## 二、模块功能详述

### 模块 1：AI 写作工作室（6 功能）

**核心价值**：AI 深度融入创作全流程，从灵感到成稿全程辅助。

| # | 功能 | 说明 |
|---|------|------|
| 1.1 | AI 智能续写 | 用户提供上文，AI 续写后续内容。可选择风格（古风/现代/科幻/悬疑等），不满意可重新生成。流式输出，逐字显示 |
| 1.2 | 灵感生成器 | 输入关键词或主题（如"末日、爱情、背叛"），AI 生成多个故事灵感/梗概供用户挑选 |
| 1.3 | 章节大纲 | 用户描述故事主题与大致走向，AI 自动生成分章大纲结构 |
| 1.4 | 角色生成器 | AI 生成角色设定卡片：姓名/性格/外貌/背景故事/角色弧光/口头禅 |
| 1.5 | AI 润色改写 | 选中文字 → 一键润色（更流畅/更文艺/更有力/更简洁四种模式），保持原意优化表达 |
| 1.6 | 写作提示 | 卡文时 AI 提供剧情走向建议、冲突点启发、反转思路 |

**实现方式**：前端编辑器 + 右侧 AI 面板 → Flask API → 拼装 System Prompt + User Prompt → 调 MiMo API（stream=True）→ SSE 流式返回 → 前端逐字渲染。

**对话历史**：AI 对话记录按 session 保存到数据库，支持切换历史会话。

---

### 模块 2：作品管理中心（6 功能）

**核心价值**：用户创作、管理自己所有作品的后台。

| # | 功能 | 说明 |
|---|------|------|
| 2.1 | 新建作品 | 选择类型（小说/诗歌/散文/剧本），填写标题、简介、封面图、标签 |
| 2.2 | 在线编辑器 | 富文本编辑器（Quill.js），支持章节管理（小说类），自动保存草稿（30秒间隔） |
| 2.3 | 草稿箱 | 未发布作品存在草稿箱，显示最后保存时间，随时继续编辑 |
| 2.4 | 已发布管理 | 查看/编辑/删除已发布作品，可切换公开/私密状态 |
| 2.5 | 分类筛选 | 按作品类型、标签、状态（草稿/已发布/私密）筛选列表 |
| 2.6 | 版本快照 | 每次保存自动记录版本，支持查看和回退到历史版本 |

---

### 模块 3：社区发现广场（6 功能）

**核心价值**：发现优秀作品、关注感兴趣的作者。

| # | 功能 | 说明 |
|---|------|------|
| 3.1 | 推荐流 | 首页卡片式/瀑布流展示热门作品（按互动量+发布时间综合排序） |
| 3.2 | 分类浏览 | 按小说/诗歌/散文/剧本 Tab 分类查看 |
| 3.3 | 全文搜索 | 按作品标题/作者昵称/标签关键词搜索 |
| 3.4 | 话题标签 | 点击标签（如 #古风 #悬疑 #科幻）聚合展示相关作品 |
| 3.5 | 编辑精选 | 每日推荐一篇精选作品（管理员后台设置） |
| 3.6 | 关注动态 | 时间线展示已关注作者的新作品、新动态 |

**预制数据**：系统预置 15+ 篇不同类型示例作品、5+ 用户账号、模拟互动数据（点赞/评论/收藏），确保初次打开内容丰富。

---

### 模块 4：阅读与互动（6 功能）

**核心价值**：沉浸式阅读体验 + 读者-作者互动。

| # | 功能 | 说明 |
|---|------|------|
| 4.1 | 沉浸式阅读器 | 清爽阅读界面，支持字体大小调节、背景色切换（白/米/暗）、翻页模式 |
| 4.2 | 目录导航 | 长篇小说按章节生成目录导航栏，点击跳转，显示当前阅读进度 |
| 4.3 | 评论系统 | 作品下方评论列表，支持盖楼回复（二级评论），作者可置顶评论 |
| 4.4 | 点赞 | 点赞作品（红心动画），点赞评论 |
| 4.5 | 收藏 | 收藏作品到个人书架，支持创建收藏夹分类管理 |
| 4.6 | 分享 | 一键生成分享卡片（作品封面+标题+简介），复制链接或生成海报图 |

---

### 模块 5：写作数据洞察（5 功能）

**核心价值**：用数据帮用户了解自己的写作习惯与进步。

| # | 功能 | 说明 |
|---|------|------|
| 5.1 | 字数统计 | 汇总总字数/今日/本周/本月，柱状图对比展示趋势 |
| 5.2 | 写作热力图 | 日历热力图（GitHub Contribution 风格），绿色深浅表示当天写作量 |
| 5.3 | 时长统计 | 记录每次编辑时长，折线图展示写作习惯变化 |
| 5.4 | 风格画像 | AI 分析用词偏好，输出雷达图：文艺/朴实/幽默/激昂/忧郁五维度 |
| 5.5 | 月度写作报告 | 每月 1 日自动生成：本月字数、写作天数、最常用词、风格总结、下月建议 |

**数据采集**：前端编辑器定时上报（每 30 秒记录一次字数+时间）→ 后端记录到 `writing_sessions` 表 → 聚合查询生成图表数据。

---

### 模块 6：知识图谱可视化（3 功能）

**核心价值**：把作品中的抽象关系变成可视化图表，答辩展示亮点。

| # | 功能 | 说明 |
|---|------|------|
| 6.1 | 角色关系图谱 | ECharts 力导向布局图，节点=角色（头像+姓名），边=关系（挚友/恋人/敌对/师徒等），不同关系颜色不同 |
| 6.2 | 剧情时间线 | 时间轴（timeline）展示故事关键事件节点，按时间顺序排列，点击展开详情 |
| 6.3 | 世界观地图 | 如果作品有虚构地理设定，可视化展示势力分布/区域关系（待版图示意） |

**预制数据**：预置 2-3 部示例作品 + 完整角色关系数据 + 时间线事件，确保演示时直接有图可看。

### 模块 7：写作挑战与共创（4 功能）

**核心价值**：以社区驱动写作动力。

| # | 功能 | 说明 |
|---|------|------|
| 7.1 | 挑战赛列表 | 展示进行中/即将开始/已结束的写作挑战，含标题/说明/时间/参与人数 |
| 7.2 | 参与挑战 | 用户报名参加挑战，在挑战下提交/关联自己的作品 |
| 7.3 | 打卡进度 | 挑战的每日打卡，进度条可视化，打卡日历 |
| 7.4 | 共创接龙 | 多人接力写作：发起人写开头 → 其他人各接一段 → AI 自动合成全文 |

**预制数据**：预置 3+ 个示例挑战赛（含进行中和已结束）+ 模拟参与记录。

## 六、技术约定

| 规则 | 说明 |
|------|------|
| 统一响应格式 | `{"code": 0, "data": {...}, "msg": "success"}` |
| 流式响应 | SSE `text/event-stream`，chunk 格式 `data: xxx\n\n`，结束标记 `data: [DONE]\n\n` |
| 数据库操作 | 全部放在 `database/db.py`，路由中不直接写 SQL |
| Prompt 模板 | 全部放在 `utils/prompt_builder.py`，便于统一调优 |
| 结构化数据 | 徽章/等级/挑战等配置数据放在 `data/` 目录 JSON 文件 |
| 预制数据 | 数据库初始化脚本 `database/seed.py`，插入示例用户+作品+互动数据 |
| 前端样式 | CSS 自定义属性体系，毛玻璃/渐变/动效风格 |
| 无构建工具依赖 | `pip install -r requirements.txt` + 前端 `npm install` 即可启动 |

## 七、开发流程

**阶段一：基础设施**
- 项目脚手架搭建（Vue3 + Flask 项目结构）
- MySQL 数据库建表 + seed 数据
- 用户认证系统（注册/登录/退出/会话）

**阶段二：核心模块**
- AI 写作工作室（衔接 MiMo API + 流式输出 + 编辑器）
- 作品管理中心（CRUD + Quill.js 编辑器集成）

**阶段三：社交模块**
- 社区发现广场 + 阅读与互动
- 用户个人主页 + 关注/粉丝体系

**阶段四：数据与创新**
- 写作数据洞察（ECharts 图表 + 数据采集）
- 知识图谱可视化 + AI 书评与推荐

**阶段五：增强与打磨**
- 写作挑战与共创
- 消息通知 + 用户成长体系
- 全局 UI 打磨 + 预制数据完善
