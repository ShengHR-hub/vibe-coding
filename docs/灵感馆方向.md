# 墨池方向变更：灵感馆路线（2026-09-03 用户拍板）

> 背景：原"阅读模块"因平台缺乏长篇内容而空转；导入外部小说（《剑来》《仙逆》等）既有版权风险又与"原创创作平台"叙事冲突。
> 决策：**取消"书/书库/外部阅读"概念**，内容单元收敛为**短句、诗词、意象等灵感素材**；产品闭环改为：
> **灵感馆（拾句/翻阅/收藏） → 引用素材 → AI 共创写作 → 原创作品**。

## 定位一句话
墨池 = AI 写作灵感生态：**以"句子/诗词"为内容单元，用灵感反哺 AI 写作**，不贪规模、链条干净。

## 范围边界（必须遵守）
- **保留**：AI 写作工作室（9 端点）、作品管理/章节/卷、原创作品阅读器（/read/:id）、社区互动、用户成长（等级/成就）、写作统计、诗词库、素材库、每日练习、挑战、图谱、AI 书评、角色扮演、连载。
- **取消（产品层）**：书库/书架/外部书籍（library_*）、以"外部书"为对象的阅读活动（进度/书签/批注/好句/打卡/报告/书评/对比，reading_*）。
- **灵感馆只装灵感内容**：materials（短句素材 6 类）+ poems（古诗词）+ 每日一句 + 用户收藏；不装书、不装整篇。
- **内容填充方式**：爬取/手动录入热门句子（用户负责数据来源与版权判断），**不消耗 token 批量生成**。
- **AI 注入打通**（核心价值）：写作请求支持携带"参考素材/风格句"，prompt_builder 与 write 端点加可选 reference 通道。

## 代码处置策略（分阶段，走 Step Loop，每步测试绿灯）
- 阶段 R（移除，多小步）：① 路由/导航/入口移除书库阅读相关页面 → ② 后端 10 个书类蓝图取消注册并删对应 routes 文件 → ③ schema 删除 12 张 library_*/reading_* 表并同步 seed 成就与 helpers 统计 → ④ 前端删除书类 views/组件（Reader 保留原创作品路径并简化）→ ⑤ 文档与测试同步。
- 阶段 F（灵感馆建设，随后）：⑥ 灵感馆统一入口与翻阅 UI（复用 poems/materials 数据）→ ⑦ reference 素材注入 AI（prompt_builder + write 端点 + 面板引用按钮）→ ⑧ 内容录入/导入工具（手动录入表单 + 可选爬虫脚本）。

## 与守则关系
本方向属用户明确指令下的**收缩型重构**：每一步仍遵守 docs/改造守则.md（最小增量、改后 pytest 全量 + build、绿灯前进、无关发现进 Backlog）。原 M1"阅读收口"清单整体作废，阅读模块 54 步实施计划不再执行。
