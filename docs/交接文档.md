## 2. 环境与启动（接手后第一件事）

### 2.1 一键启动（推荐）
```powershell
cd /d D:\Claude工作文件\inkstone
# 双击 bat（带窗口，适合演示）
.\启动开发服务.bat
# 或命令行静默（适合 agent / 无人值守）
powershell -ExecutionPolicy Bypass -File .\dev-up.ps1
# 停止
powershell -ExecutionPolicy Bypass -File .\dev-down.ps1
```

### 2.2 手动启动（脚本内部等价动作）
```bash
# 一次性初始化（库已就绪时无需重复）
mysql -u root -p123456 < server/database/schema.sql
cd server && python -m database.seed
# 后端 :5000     前端 :5173
cd server && python app.py
cd client && npm install && npm run dev
```

### 2.3 测试
```bash
cd server && python -m pytest tests -q     # 96 用例，隔离库 inkstone_test
cd client && npm run test:util             # 前端渲染工具单测
cd e2e && npx playwright test              # E2E（channel=msedge，Mock AI）
```

### 2.4 常见故障排查
| 症状 | 处理 |
|---|---|
| 提示"MySQL 连不上" | 启动本地 MySQL8 服务；确认已跑过 schema.sql+seed |
| 提示"缺少 server\.env" | 复制 `.env.example` 为 `.env` 并填 SECRET_KEY / MYSQL_* / AI_* |
| 端口被占用 | 脚本会自动跳过；或先 `dev-down.ps1` 再启动 |
| 前端 60s 未就绪 | 看 `server/logs/dev-frontend.log` / 前端窗口报错 |
| AI 报错/超时 | 查 `server/logs/dev-backend*.log`；确认 .env 中 AI_PROVIDER/bigmodel thinking 配置 |
